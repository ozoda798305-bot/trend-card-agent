# 외국인을 위한 유행 표현 카드뉴스 에이전트

구글 트렌드와 유튜브에서 요즘 뜨는 한국어 표현을 찾아, 금지 주제를 거르고, 외국인용 영어 카드뉴스 7장 문구·캡션·해시태그를 만든다.
디지털마케팅전략 조별 과제(2026 가을) 결과물이다.

## 흐름
1. **후보 찾기** – 구글 트렌드 「뜻·신조어·밈·줄임말」 급상승 관련 검색어(`find_candidates.py`, pytrends) + 유튜브 신조어 풀이 영상 제목
2. **유튜브 검증** – 표현마다 「표현 뜻」으로 최근 30일 풀이 영상 수·조회수를 센다(`youtube_check.py`, YouTube Data API v3)
3. **AI 검수** – Gemini 가 근거 영상 제목·설명을 읽고 정치·혐오 등 금지 주제와 일반 단어를 거른다
4. **사람 선택** – `04_자료/run_<시각>/결과요약.md` 를 보고 표현 1개를 고른다
5. **카드 문구** – Gemini 가 근거 영상으로 뜻·예문과 카드 7장 문구를 쓰고, 코드가 글자 수·해시태그 수를 검사해 넘은 부분만 최대 2번 다시 쓰게 한다
6. **카드 PNG 7장** – `render_cards.py`: 디자인은 매번 AI(Gemini)가 표현 분위기에 맞게 새로 짜고, 선생님 시그니처(@ozoda_korean 배지, Today's Korean #번호, 한글 표현 굵게 + 노란 밑줄·로마자 알약, 시그니처 노란색 #FFD43B, 고정된 마지막 장)는 코드가 넣는다. 코드가 글자 넘침·대비·시그니처 가려짐·한글 폰트를 검사하고, 걸리면 다시 디자인(최대 2번), 그래도 안 되면 기본 디자인
7. **사람 승인 뒤 게시** – 뜻을 사전과 대조하고, 카드 PNG 를 만들어 Blotato 로 예약한다(이 저장소 밖)

## 실행
```bash
pip install -r requirements.txt   # 카드 PNG 는 Chrome 이 설치돼 있어야 한다(playwright 가 설치된 Chrome 을 쓴다)
cp .env.example .env        # 키 2개를 넣는다
python3 run_pipeline.py find                       # 1부: 후보 표
python3 run_pipeline.py make --choose 줴줴이야     # 2부: 카드 문구
```
결과는 `04_자료/run_<시각>/` 에 JSON·Markdown 으로 남는다.

## 기준
- 카드: Title 40자 이내, 문장 6개 각 20~100자, 캡션 300자 이내(해시태그 없음), 해시태그 정확히 5개(인스타그램 제한)
- 유튜브 검증: 제목에 표현과 풀이어(뜻·의미·신조어·밈·줄임말·유행어)가 함께 있는 최근 30일 영상 5개 이상이면 「사용 확인」
- 금지 주제: 정치, 사건사고, 욕설·비하·혐오 표현, 성적 표현, 연예인 사생활

## 한계
- pytrends 는 비공식 라이브러리라 구글이 429로 막을 수 있다. 막히면 이전 후보 파일로 대신한다.
- Gemini 무료 등급은 바쁠 때 503을 낸다. 모델을 바꿔 가며 다시 시도하고, 검수에 실패하면 「사람 확인」으로 표시한다.
- 뜻은 유튜브 풀이 영상을 근거로 한 AI 초안이다. 게시 전 사람이 사전과 대조한다.

## 매일 자동 실행과 예약
- **매일 아침 8시(한국)**: GitHub Actions(`.github/workflows/daily_find.yml`)가 후보 찾기만 돌려 `daily/run_<시각>/` 에 올린다. 웹 앱은 이 최신 후보 표를 보여 준다. 저장소 Settings → Secrets and variables → Actions 에 `YOUTUBE_API_KEY`, `GEMINI_API_KEY` 가 있어야 한다.
- **고르기·카드·승인은 사람**이 웹 앱에서 한다.
- **예약(④)**: 승인 체크 3개 뒤 「📅 예약」→ `blotato_post.py`. 게시 시각은 사람이 고르지 않고 **실행이 시작된 날 저녁 7시**로 자동으로 정한다(이미 지났으면 다음 날 7시). Blotato API 는 유료 플랜 전용이라 키가 없으면 **FAKE** 로 돈다: 보낼 요청(캡션·이미지 7장·게시 시각)을 `06_예약.json` 에 저장만 하고 Blotato 는 부르지 않는다. 키(`BLOTATO_API_KEY`)를 넣으면 같은 버튼이 실제 예약을 한다.
- 실제 게시는 사람이 인스타 앱이나 Meta Business Suite 예약 기능으로 한다.

## 여러 사람이 쓸 때(사람별 맞춤)
- Streamlit Secrets 에 `[auth]`(구글 로그인)를 넣으면 로그인한 사람마다 따로 돈다. 넣지 않으면 운영자 혼자(`DEMO_PASSWORD`).
- 사람마다 따로: **이미 쓴 표현 목록·Today's Korean #번호·카드 배지 계정(@...)·하루 실행 횟수(5번)**.
- 함께 쓰는 것: 아침 8시 후보 표(`daily/`). 표에서 그 사람이 이미 쓴 표현만 「이미 씀」으로 바뀌고 고를 수 없다.
- 저장: `users/<id>/used.json`, `users/<id>/profile.json`. id 는 이메일의 해시 12자리(이메일을 저장소에 쓰지 않는다).
- 웹 서버 파일은 재시작 때 지워지므로 Secrets 의 `GITHUB_TOKEN`(이 저장소만, Contents 읽기·쓰기 fine-grained token)으로 GitHub 에 직접 기록한다.

## 이미 쓴 표현은 다시 쓰지 않는다
- 승인 뒤 ④ 예약 버튼을 누르면 그 표현이 그 사람의 `used.json` 에 들어간다(날짜·번호·결과 폴더). **영원히 금지.**
- 띄어쓰기는 무시하고 같은 표현으로 본다. 카드 만들기도 막는다.
- 「Today's Korean #N」 = 그 사람이 이미 쓴 표현 개수 + 1. 디자인을 다시 만들어도 번호는 같다.
